# Pinna 0.5.0-beta.1

Music Assistant can play to the satellite over Sendspin, in step with other speakers. The dashboard can ask for a password. Updates can install by themselves in a window you choose, and a satellite without Wi-Fi opens a setup hotspot.

## Before you update

This is a beta: it goes to satellites whose **Updates** setting is `beta`.

- **The Wi-Fi driver changed.** The setup hotspot needs a part of the MT8163
  Wi-Fi driver that earlier releases left out. That kernel hasn't run on an
  Echo yet. The update's health check doesn't need Wi-Fi: if the satellite
  doesn't join your network after the update, it stays on the new version,
  and you reach it only over USB. Keep the cable at hand, and see
  [Recovery](https://getpinna.dev/docs/recovery/).
- **The dashboard offers a password.** The first time you open it after the
  update, it asks you to set one or to leave it open. Leaving it open changes
  nothing. Before you set one: Prometheus and agents that call `/metrics` or
  `/mcp` need tokens, which you can create first. If you later go back to
  0.4.0-beta.3 or older, that version doesn't ask for the password.

## Highlights

### Play music with Sendspin

Turn on **Sendspin** under **Voice & sound** > **Media sources**, or with the
**Sendspin** switch in Home Assistant. Music Assistant 2.10.7 or later then
lists the satellite as a player and plays to it in step with the other
Sendspin speakers of a group. The music goes through the satellite's own audio
processing, so the wake word keeps working, and replies, announcements and
timer alarms play over it. Sendspin is experimental and off until you turn it
on. It is tested against Music Assistant's server on a computer, not yet on
an Echo. See [Play music with Sendspin](https://getpinna.dev/docs/sendspin/).

### A password for the dashboard

The dashboard can ask for a password. To set one, select **Set a password…**
on **System** under **Dashboard password**, and press **Action** on the
satellite when the ring circles white. With a password, the dashboard, the
control API and the log need you to be signed in, and the metrics and `/mcp`
need [tokens](https://getpinna.dev/docs/dashboard/#tokens-for-prometheus-and-agents).
It also closes the ESPHome API to a Home Assistant that has no key for the
satellite yet, and group joins, until you open them. The password travels
unencrypted, so use one that you use nowhere else. See
[Who can use the dashboard](https://getpinna.dev/docs/dashboard/#who-can-use-the-dashboard).

### Install updates automatically

Set **Install updates** to **Automatically** on **System**, under
**Updates**. The satellite then installs a new release by itself at a random
minute inside your install window, 03:00 to 05:00 unless you change it, and
restarts only when it is Idle, with no timer set and nothing playing. A
release that needs a new boot image, or a version that was rolled back, never
installs by itself. **Manually** stays the default. See
[Install updates automatically](https://getpinna.dev/docs/update/#install-updates-automatically).

### Set up Wi-Fi from your phone

A satellite with no saved Wi-Fi network, such as a newly flashed one, runs its
own network, **Pinna setup** followed by its hostname, with the password
`pinnasetup`. Join it with your phone, and the dashboard opens: choose your
network on **Network**. This needs no cable, which helps on the Echo (2nd
gen), whose USB is in its base. The hotspot is tested in the virtual machine,
not yet on an Echo, and the USB cable still works. See
[Connect to Wi-Fi](https://getpinna.dev/docs/flash/#connect-to-wi-fi).

## New in Home Assistant

- **Sendspin** (switch): turns the Sendspin player on or off.
- **Install updates** (select): `Manually` or `Automatically`.
- **Install window start** and **Install window end** (time): when automatic
  installs may happen, in the satellite's time zone.

## Fixed

- In a satellite group, the dashboard marks another satellite as a member only
  when it announces the address that the member's signed calls come from.
  Before, a device on your network could copy a member's MAC address to look
  like it.
