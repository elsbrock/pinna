# Pinna 0.4.0-beta.3

When you add a microWakeWord model, such as one from microwakeword.com, the satellite now says that it is one, instead of "The model crashed the loader."

## Before you update

This is a beta: it goes to satellites whose **Updates** setting is `beta`.

## Fixed

- The satellite refuses a microWakeWord model with a reason that names it as
  one. These models are for ESPHome devices such as Voice PE, and Pinna can't
  run them: use an openWakeWord model of the word, `.onnx` or `.tflite`. See
  [The device refuses a wake word](https://getpinna.dev/docs/troubleshooting/#the-device-refuses-a-wake-word).

## All changes

Changes since 0.4.0-beta.2.

### Fixed

- A streaming microWakeWord model is refused as one, not as a crash (pinna-wakeword)
