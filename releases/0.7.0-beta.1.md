# Pinna 0.7.0-beta.1

Pinna runs on the Echo Dot (5th gen). The dashboard gets a light and dark theme switch, Help on the System page, and Open an issue, which fills in GitHub's issue form for you.

## Before you update

This is a beta: it goes to satellites whose **Updates** setting is `beta`.

- **This release hasn't run on an Echo Dot (2nd gen) or an Echo (2nd gen)
  yet.** Its root image is compressed differently, and its kernel was rebuilt
  with the patches for the Echo Dot (5th gen). If the new version doesn't
  start, the satellite goes back to the previous one by itself. To go back
  by hand, see
  [Go back to an older version](https://getpinna.dev/docs/update/#go-back-to-an-older-version).

## Highlights

### The Echo Dot (5th gen)

Pinna runs on the Echo Dot (5th gen), model C2N6L4. It doesn't run on the
Echo Dot with clock (5th gen) or the Echo Pop. The ring, the buttons, the
microphone switch and the speaker work. The satellite hears through all three
microphones with its own sound removed, and the wake word and requests through
Home Assistant work. Updates install over the air, as on the other Echos.

You install it from TWRP. First unlock the device with
[firebreak](https://github.com/Gamer92000/firebreak), which needs wires
soldered to the USB test pads under its foot. Then `install-echo-dot-5.sh`
writes Pinna into slot A from your computer and leaves TWRP in slot B until the
first update. This release carries the files the script needs:
`install-echo-dot-5.sh`, `pinna-boot-mt8519.itb`, the root image,
`pinna-bootctl-armv7` and `SHA256SUMS`. See
[Install on the Echo Dot (5th gen)](https://getpinna.dev/docs/flash/#install-on-the-echo-dot-5th-gen),
and [Devices](https://getpinna.dev/docs/devices/#echo-dot-5th-gen) for what
works.

### Open an issue, and Help

On **System** › **Logs**, **Open an issue** takes the place of Copy for an
issue. It opens GitHub's issue form in a new tab with the Satellite field
filled in, and copies the log for you to paste into its Log field. Issues are
public, so read the log before you post it.

**System** has a Help group: Report a problem, Ask a question, Share feedback
and Read the docs. The sidebar has a Feedback link. A new discussion carries
one line with the version, the device and the mode, and nothing that names you
or your network.

### Light and dark theme

The dashboard followed the system's theme only. A button next to the logo at
the top of the sidebar now switches between System, Light and Dark. On a
phone, the switch is under **System** › **This browser** › **Theme**. The
choice is kept in your browser, not on the satellite.

## Other changes

- **System** › **Logs** keeps the width of the other pages. A line names its
  level only when it is a warning or an error, and those lines stand out.
  Copy and Download are icon buttons.
- The root image is smaller, so an update downloads less: Perl, character
  sets the satellite never uses and documentation are gone, and the image is
  compressed more tightly.

## Fixed

- **Copy** on the Logs page says when the browser didn't copy, and points to
  Download, instead of reporting a copy that didn't happen.
- On a phone, the Logs page keeps the newest line in view.
- A restart no longer waits 90 seconds for the login on the USB serial
  console to end.
