# Pinna 0.5.0-beta.2

A fix for the setup hotspot, which refused every phone and computer that tried to join. In the dashboard, updates, the password and tokens, and the satellite group have pages of their own.

## Before you update

This is a beta: it goes to satellites whose **Updates** setting is `beta`.

- **The Wi-Fi driver changed again.** The fix for the setup hotspot is in the
  MT8163 Wi-Fi driver, and that kernel hasn't run on an Echo yet. It changes
  only what the hotspot advertises; joining your network works as before. The
  update's health check doesn't need Wi-Fi: if the satellite doesn't join your
  network after the update, it stays on the new version, and you reach it only
  over USB. Keep the cable at hand, and see
  [Recovery](https://getpinna.dev/docs/recovery/).

## Highlights

### Settings have pages of their own

**System** is now a short page with rows that open **Updates**, **Password
and tokens** and **Logs**. Each row says first what needs a look: a failed
install, updates turned off, no password set, or a last start that crashed.
The satellite group moved from **Assistant** to its own page,
**Assistant > Satellite group**. Links to `#/updates` still open the updates.
See [What the dashboard shows](https://getpinna.dev/docs/dashboard/#what-the-dashboard-shows).

## Other changes

- The **Updates** row says when a developer's update address replaces the
  channel.
- The dashboard shows Pinna's new mark, and sub-pages in the sidebar hang from
  a line under their section.
- The kernel's drivers and patches that come from LibreEcho credit it.

## Fixed

- The setup hotspot advertises the basic rates a client has to support, so
  phones and computers are no longer refused when they join. Not yet tested
  on an Echo.
- When `/metrics` or `/mcp` refuse a request without a token, the message says
  where to create one: **System › Password and tokens**.
- On **System**, the rows read as plain sentences, and the sidebar lists the
  pages in the same order as the page.

## All changes

Changes since 0.5.0-beta.1.

### New

- Updates, and the password and tokens, get their own pages under System (dashboard)
- The satellite group gets its own page under Assistant (dashboard)
- The Updates row says when a developer's address replaces the channel (dashboard)
- The Logs row on System looks like the rows beside it (dashboard)

### Fixed

- The token refusals point to System > Password and tokens (pinnad)
- System's rows read plainly, and its pages are listed in the hub's order (dashboard)
- The token refusals write the dashboard path as the dashboard does (pinnad)
- Credit LibreEcho in the ported drivers and patches (kernel)
- The setup hotspot advertises the basic rates it requires (kernel)
