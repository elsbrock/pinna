# Contributing

## What gets merged

Use whatever tools you like, AI included. Every change is held to the same bar:

- You understand every line and can answer questions about it in review.
- The description says what changed and why, in plain words. If the
  maintainer can't follow it, it won't be merged.
- Say how you tested it and, for anything that runs on the Echo, on which
  device. "It builds" is not tested.
- One change per PR, kept small.

Large diffs nobody can explain, invented APIs, and speculative refactors
are closed without a detailed review.
